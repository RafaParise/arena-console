# Manual do Usuário - ARENA

## Primeiro Uso

1. Clique duas vezes em ARENA.bat
2. Aguarde a inicialização
3. Use a interface web que será aberta

## Adicionar Jogos

Crie pastas para cada usuário:
```
jogos/usuarios/SeuNome/nome-do-jogo.zip
```

## Adicionar BIOS

Organize por console e região:
```
BIOS/PS2/BR/bios.bin
BIOS/PS1/US/bios.bin
```

## Sincronização

Para manter atualizado:
```cmd
python sync_github.py
```

## Recursos

- 47 consoles emulados
- Multiplayer local (até 5 jogadores)
- Portátil - funciona de pen drive
- Sincronização automática com GitHub
