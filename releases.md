## 🚀 Como Baixar e Usar

### Passo 1: Baixar
Clique no link acima ou:
```bash
git clone -b auditoria https://github.com/RafaParise/ARENA.git
```

### Passo 2: Entrar na pasta
```bash
cd ARENA/ARENA-unificado
```

### Passo 3: Executar
```bash
ARENA.bat
```

## ⚠️ Importante

- **Jogos/ROMs:** Não inclusos no repositório por questões legais
- **BIOS:** Não incluídos - devem ser adquiridos separadamente
- **Tamanho:** Aproximadamente 150MB (sem jogos/BIOS)

---

## 🎮 Para Adicionar Jogos

1. Crie as pastas de jogos em `jogos/usuarios/SeuNome/`
2. Adicione os arquivos dos jogos
3. O ARENA detecta automaticamente
